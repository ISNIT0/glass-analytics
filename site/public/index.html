Analytics that lives in your Cloudflare account.

Web analytics, product analytics, session replay and A/B tests. Deployed by one command, queried by your coding agent, and open source. Your data never leaves your account.

$ npx @glassanalytics/cli init

Or paste this into your coding agent:

Add Glass analytics to this project: run npx @glassanalytics/cli init, track signups and purchases, then show me today's visitors.

Needs a Cloudflare account and an API token. Takes about two minutes.

From zero to answers

  1. Run one command

    npx @glassanalytics/cli init creates a D1 database, an R2 bucket and a Worker in your account, then writes instructions and an MCP server config for your agent.

  2. Add one script tag

    Or let your agent do it. Pageviews, clicks, errors and web vitals arrive straight away; custom events are one line.

  3. Ask your agent

    "Why did signups drop last week?" It runs funnels, reads session replays as text, and can ship a fix behind an experiment.

What that looks like

An example session in a coding agent with the Glass MCP server.

Signups dropped this week. Find out why.

overview from: "-7d"

Visitors steady (+2%). signup_completed down 31% vs previous period.

query_funnel steps: pricing, signup_started, signup_completed; breakdown: browser

Safari: 412 started, 38 completed (9.2%). Chrome: 64.0%. Firefox: 61.5%.

list_replays with_errors: true

summarise_replay session: "01a2…"

00:41 Rage-clicked "Create account" (button) ×5
00:42 ERROR TypeError: crypto.randomUUID is not a function

Safari 15 has no crypto.randomUUID, so the signup form throws on submit. I've replaced it with a fallback and added a test. Want me to ship it behind a flag and watch the funnel?

Four tools on one event stream

Web analytics
Visitors, pages, referrers, campaigns, countries and devices, plus errors and Core Web Vitals. Cookieless mode needs no consent banner.
Product analytics
Trends, funnels and retention on any event, filtered or broken down by any event or person property. Raw SQL when you need it.
Session replay
rrweb recordings with inputs masked, and a text transcript of each session (clicks, rage clicks, errors) that agents can read.
Flags and experiments
Feature flags evaluated in your Worker, and A/B tests with Bayesian results and sample-ratio checks.

Your account, your data

  • Events, people and recordings live in your D1 database and R2 bucket. Glass has no servers.
  • Keep data in the EU with glass init --eu.
  • Delete a person and everything about them with one call.
  • This page loads nothing from third parties. Neither does the Glass dashboard.

What it costs

Your Cloudflare bill, nothing else. The default D1 store runs on the Workers free plan for small sites; Workers Paid ($5 a month) raises the limits. For large volumes, --lake streams events to Iceberg tables in R2 and queries them with Basin SQL.
